【完全無料】Googleドライブの自炊本を全デバイスで爆速ストリーミング！「Cloud BookReader」の導入＆操作マニュアル

Googleドライブに保存してある自炊マンガや書籍（PDF / ZIP / CBZ / EPUB）を、ダウンロード待ち時間ゼロ・容量消費ゼロ で快適に読めるWebリーダーアプリ 「Cloud BookReader」 を公開しました！

スマートフォン、タブレット、PCなどあらゆる端末からアクセスでき、「PCで読んだ続きを、外出先のスマホで1秒で再開」 できます。

📖 Cloud BookReader とは？

従来の電子書籍リーダーアプリのように 「端末に本を丸ごとダウンロードして空き容量を圧迫する」 必要はもうありません。

✨ 主な特徴

  • ⚡ ダウンロード待ち0秒（HTTP Range Request ストリーミング）: 大容量のPDFやZIPマンガでも、今開いているページだけを瞬時に取得。
  • 🔄 クラウドしおり・進捗・表紙の完全自動同期: 読んだページや表紙サムネイルはGoogleドライブの専用隠し領域（appDataFolder）に自動保存。
  • 📚 幅広いファイル形式に対応: PDF、ZIP/CBZ（マンガ見開き）、EPUB（縦書き・文字サイズ変更）。
  • 📱 PWA対応（全画面ネイティブアプリ化）: ホーム画面に追加するだけで、アドレスバーのない全画面アプリとして起動。
  • 🎨 上質な2つの読書空間: Midnight（木造書斎・ダーク）と Paper（和紙ミニマル・ライト）。
  • 🔒 完全無料＆最高峰のプライバシー保護: あなた専用の無料VercelアカウントとGoogleアカウントのみで動作。

🚀 5分でできる！自分専用の本棚を作る手順

ステップ1: Google Cloud で無料APIキーを取得する

  1. Google Cloud Console にアクセスし、Googleアカウントでログインします。
  2. 「新しいプロジェクト」を作成します。
  3. 「APIとサービス」→「ライブラリ」から Google Drive API を有効にします。
  4. 「OAuth 同意画面」でユーザータイプ「外部」を選択し、スコープ（.../auth/drive.readonly と .../auth/drive.appdata）を追加。テストユーザーにご自身のGmailを追加します。
  5. 「認証情報」→「認証情報を作成」→「OAuth クライアント ID」（ウェブ アプリケーション）を作成し、クライアント ID と クライアント シークレット をメモします。

ステップ2: Vercel にワンクリックデプロイ（完全無料）

以下のボタンをクリックしてVercelにログインし、環境変数を入力してデプロイします：

  • GOOGLE_CLIENT_ID: ステップ1で取得したクライアントID
  • GOOGLE_CLIENT_SECRET: ステップ1で取得したクライアントシークレット
  • NEXTAUTH_SECRET: 適当なランダム文字列

ステップ3: Google Cloud に本番URLを登録（仕上げ）

発行されたVercelのURLを、Google Cloud Console の OAuth クライアント設定に追加します：

  • 承認済みの JavaScript 生成元: https://あなたのアプリ名.vercel.app
  • 承認済みのリダイレクト URI: https://あなたのアプリ名.vercel.app/api/auth/callback/google

📱 スマホ・タブレットでアプリ化する（PWA設定）

  • iPhone / iPad (Safari): 画面下の「共有ボタン」→「ホーム画面に追加」
  • Android (Chrome): 右上メニュー「︙」→「アプリをインストール」

💡 便利な機能と操作マニュアル

  • 本棚トップの固定: いつも本を入れているフォルダを開いて「このフォルダを本棚トップにする」を押すと、次回から直接開きます。
  • 直前フォルダへの自動復帰: 本を読み終えて戻るを押すと、直前の巻があるフォルダへ瞬時に戻ります。
  • 続きから読むの整理: 直近5件の履歴が表示され、不要な履歴は「×ボタン」でいつでも削除可能です。

❓ よくある質問（FAQ）

Q. Googleログイン時に「このアプリは確認されていません」と表示されます
自作アプリのため表示されます。画面左下の「詳細」→「（安全ではないページ）に移動」を押してログインしてください。

Q. 完全無料でずっと使えますか？
はい。Google API と Vercel の無料枠内で運用できるため、費用は一切かかりません。
