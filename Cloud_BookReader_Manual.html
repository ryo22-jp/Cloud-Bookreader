【完全無料・自分専用】Googleドライブの自炊マンガ・書籍を全デバイスで爆速ストリーミング！「Cloud BookReader」導入＆操作マニュアル

Googleドライブに保存してある自炊マンガや電子書籍（PDF / ZIP / CBZ / EPUB）を、ダウンロード待ち時間ゼロ・端末の容量消費ゼロ で快適に読めるクラウドWebリーダー 「Cloud BookReader」 のご紹介です。

スマートフォン、タブレット、PCなどあらゆるデバイスに対応し、「PCで読んだ続きを、外出先のスマホで1秒で再開」 できます。

🛡️ なぜ「自分専用（セルフホスト）」なのか？

本アプリは、誰でも 無料のVercelサーバー ＋ ご自身のGoogle Cloudキー を使って、「誰にも邪魔されない完全プライベートな自分専用リーダー」 を約5分で立ち上げられるように設計されています。

🔍 アプリの信頼性と透明性（ソースコードの確認方法）

「自分のGoogleドライブを連携しても本当に安全か？」を誰もが自身の目で検証できます。

  1. 全ソースコードをGitHubで完全公開: すべてのプログラムコードは GitHubリポジトリ（オープンソース） で公開されており、不正なデータ送信がないことを1行残らず確認できます。
  2. ソースコードから直接ビルド（改ざん不能）: 「Deploy to Vercel」でGitHub上のコードがあなたのGitHubに複製され自動ビルドされるため、開発者が裏で別のコードを差し挟む余地はありません。
  3. ブラウザ（F12）で通信先をいつでも検証可能: 開発者ツールの「Network」タブから、通信相手が「Google公式サーバー」と「あなた自身のVercelサーバー」のみであることを直接確認できます。

🚀 【約5分】自分専用リーダーの立ち上げ手順（完全図解）

ステップ1: Google Cloud で無料APIキーを取得（約3分）

  1. Google Cloud Console でプロジェクトを新規作成。
  2. 「ライブラリ」から Google Drive API と Google Picker API を検索し「有効にする」。
  3. 「OAuth 同意画面」で「外部」を選択し、スコープに drive.readonly と drive.appdata を追加。「テストユーザー」にご自身のGmailを登録。
  4. 「認証情報」→「OAuth クライアント ID」を作成し、「クライアント ID」と「クライアント シークレット」をコピー。

ステップ2: Vercel にワンクリックでデプロイ（約2分）

以下のボタンをクリックして、Vercelへデプロイします：

▲ Deploy to Vercel
環境変数名入力する値
GOOGLE_CLIENT_IDコピーしたクライアントID
GOOGLE_CLIENT_SECRETコピーしたクライアントシークレット
NEXTAUTH_SECRETランダムな英数字32文字以上
NEXTAUTH_URLhttps://my-cloud-bookreader.vercel.app（発行URL）

ステップ3: Google Cloud にURLを登録して完成！

  1. Google Cloud の「OAuth 2.0 クライアント ID」に発行されたURLを追加：
    • 承認済みの JavaScript 生成元: https://発行されたあなた専用のURL
    • 承認済みのリダイレクト URI: https://発行されたあなた専用のURL/api/auth/callback/google
  2. Vercelの NEXTAUTH_URL を確定URLにして再デプロイ。

📖 読書機能・操作マニュアル

  • 📥 オフライン保存（最大5冊）: 「📥 アイコン」を押すと、端末に一時保存され、機内モードや電波のない場所でも読書可能。
