スマートフォン、タブレット、PCなどあらゆるデバイスに対応し、「PCで読んだ続きを、外出先のスマホで1秒で再開」 できます。

🛡️ なぜ「自分専用（セルフホスト）」なのか？

本アプリは、誰でも 無料のVercelサーバー ＋ ご自身のAPIキー を使って、「誰にも邪魔されない完全プライベートな自分専用リーダー」 を約5分で立ち上げられるように設計されています。

🔍 アプリの信頼性と透明性（ソースコードの確認方法）

「自分のクラウドやNASを連携しても本当に安全か？」を誰もが自身の目で検証できます。

  1. 全ソースコードをGitHubで完全公開: すべてのプログラムコードは GitHubリポジトリ（オープンソース） で公開されており、不正なデータ送信がないことを1行残らず確認できます。
  2. ソースコードから直接ビルド（改ざん不能）: 「Deploy to Vercel」でGitHub上のコードがあなたのGitHubに複製され自動ビルドされるため、開発者が裏で別のコードを差し挟む余地はありません。
  3. ブラウザ（F12）で通信先をいつでも検証可能: 開発者ツールの「Network」タブから、通信相手が「公式クラウドAPI／自宅NAS」と「あなた自身のVercelサーバー」のみであることを直接確認できます。

☁️ Nextcloud の設定・接続手順

Nextcloud 上の自炊本も、WebDAV を通じてダウンロード待ち時間ゼロでストリーミング読書できます。

1. Nextcloud 側でアプリパスワードを発行（推奨）

安全のため、通常のパスワードではなく **アプリパスワード** の利用を推奨します（2段階認証をご利用の場合は必須です）。

  1. Nextcloud のWeb画面にログインします。
  2. 右上のユーザーアイコン → 「個人設定」 → 左メニュー 「セキュリティ」 を開きます。
  3. ページ下部の「デバイスとセッション」でアプリ名（例: Cloud-Bookreader）を入力し、「新しいアプリパスワードを作成」 をクリックします。
  4. 表示されたユーザー名とパスワードをコピーします。

2. アプリでの接続

  1. トップページの 「Nextcloud で接続」 ボタンをクリック。
  2. 以下の3項目を入力します：
    • Nextcloud サーバーURL: 例 https://cloud.example.com
      ※トップページのURLを入力すれば、WebDAVパス（/remote.php/dav/files/ユーザー名）は自動補完されます。
    • ユーザー名: Nextcloud のユーザー名
    • パスワード: 先ほど発行したアプリパスワード（または通常のパスワード）
  3. 「Nextcloud に接続」 をクリック。

3. 本棚フォルダの選択

接続後、本棚画面で 「Nextcloudから本棚フォルダを選択」 を押し、自炊書籍が入ったフォルダを指定すれば完了です！

🔵 Microsoft OneDrive の設定手順

トップページの 「OneDrive でログイン」 ボタンをクリックし、お使いの Microsoft アカウントでサインインするだけです。本棚画面でアプリ内フォルダピッカーから本棚フォルダを選択してください。

🏠 自宅NAS（WebDAV）の設定・接続手順

1. NAS側のWebDAVサーバー有効化

  • Synology NAS: パッケージセンターから「WebDAV Server」をインストールし、「HTTPS を有効にする (ポート: 5006)」を適用。
  • QNAP NAS: コントロールパネル →「アプリケーション」→「WebDAV」を開き有効化（ポート: 5001等）。

2. アプリでの接続

  1. トップ画面の 「自宅NAS (WebDAV) で接続」 をクリック。
  2. サーバーURL、ユーザー名、パスワードを入力して「NASに接続」。
  3. フォルダ選択で、自炊本が入っている共有フォルダ（例: /volume1/manga）を指定すれば完了！

🔄 すでにアプリをご利用中の方へ：最新版への更新（アップデート）手順

過去に Vercel ＋ GitHub で自分専用リーダーを作成された方は、1クリックで最新機能（Nextcloud対応など）を取り込めます。

方法1: GitHubの「Sync fork」を使う（最も簡単・おすすめ）

  1. GitHubにログインし、ご自身のアカウントにフォークされている Cloud-Bookreader リポジトリを開きます。
  2. リポジトリ上部の緑色ボタン付近にある 「Sync fork」 をクリックします。
  3. 「Update branch」 をクリックします。
  4. これだけで本家の最新コードが同期され、Vercelが自動検知して約1〜2分で最新版が自動デプロイ されます！

💡 環境変数の追加は不要です: 今回のアップデートは環境変数の変更・追加が不要なため、ブランチ更新だけで即座にNextcloud接続ボタンが反映されます。

方法2: Git コマンドで更新する場合

git fetch upstream master
git merge upstream/master
git push origin master
