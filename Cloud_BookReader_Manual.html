【完全無料】Googleドライブの自炊マンガ・書籍を全デバイスで爆速ストリーミング！「Cloud BookReader」の使い方ガイド

Googleドライブに保存してある自炊マンガや電子書籍（PDF / ZIP / CBZ / EPUB）を、ダウンロード待ち時間ゼロ・端末の容量消費ゼロ で快適に読めるWebリーダーサービス 「Cloud BookReader」 を公開しました！

スマートフォン、タブレット、PCなどあらゆるデバイスに対応し、「PCで読んだ続きを、外出先のスマホで1秒で再開」 できます。

面倒なアプリのインストールやアカウント登録、API設定などは一切不要。Googleアカウントでログインして自分の本棚フォルダを選ぶだけ（約10秒） で、誰でも今すぐ無料で利用できます。

🌐 サービスURL（今すぐ無料で使えます）

https://reader.puzzleout.net

📖 Cloud BookReader とは？

従来の電子書籍リーダーアプリのように 「何百メガもある本をスマホに丸ごとダウンロードして空き容量を圧迫する」 必要はもうありません。

✨ 主な特徴

  • ⚡ ダウンロード待ち0秒（HTTP Range Request ストリーミング技術）: 500MBを超える大容量ファイルでも、今開いているページだけを瞬時に取得。端末容量を消費しません。
  • 📥 最大5冊までのオフライン保存（機内モード・ギガ節約対応）: 外出先や地下鉄で読みたい本だけ、自宅のWi-Fi環境でワンタップ事前ダウンロード（最大5冊）。通信ゼロで爆速読書できます。
  • 🔄 クラウドしおり・進捗・表紙の完全自動同期: 読んだページや表紙サムネイルはGoogleドライブの専用隠し領域（drive.appdata）に自動保存。
  • 📚 幅広いファイル形式に対応: PDF、ZIP/CBZ（マンガ見開き）、EPUB（縦書き・文字サイズ変更）。
  • 📱 PWA対応（全画面ネイティブアプリ化）: ホーム画面に追加するだけで、アドレスバーのない全画面アプリとして起動。
  • 🎨 目に優しい2つの読書空間: Midnight（木造書斎・ダーク）と Paper（和紙ミニマル・ライト）。
  • 🛡️ 読み取り専用 ＋ 専用隠し領域の安全設計: マンガや書籍は「読み取り専用（drive.readonly）」で取得し、ファイルを編集・削除することはシステム上絶対にできない安心設計です。

📥 オフライン保存（ダウンロード）の使い方

  1. 書籍一覧の右側にある 「📥（ダウンロード）」アイコン をクリックします。
  2. 数秒〜十数秒でダウンロードが完了し、「✅ 保存済」 バッジに変わります。
  3. 保存した本は、電波のない場所（機内モードや地下鉄）でも通信量ゼロ・爆速 で読書できます。
  4. 本棚上部の 「保存リストを見る」 から、合計容量の確認や削除（ゴミ箱アイコン）がいつでも行えます。

🚀 かんたん3ステップ！使い方ガイド（所要時間：10秒）

  1. サイトにアクセスしてログイン: https://reader.puzzleout.net を開き、「Googleアカウントでログイン」を押します。
  2. 本棚にするフォルダを選択: 「Googleドライブから本棚フォルダを選択」を押し、自分の「マンガ」や「自炊本」フォルダを選んで「選択」を押します。
  3. 読書スタート！: フォルダ内の本が一覧表示され、読みたい本をタップすればすぐに読書が始まります。

📱 スマホ・タブレットでアプリ化する（PWA設定）

  • iPhone / iPad (Safari): 画面下の「共有ボタン」→「ホーム画面に追加」
  • Android (Chrome): 右上メニュー「︙」→「アプリをインストール」

❓ よくある質問（FAQ）

Q. 完全無料で利用できますか？
はい、完全無料です。利用料金や課金は一切発生しません。

Q. Googleドライブ内のファイルを勝手に編集・削除される心配はありませんか？
一切ありません。書籍データは「読み取り専用」で取得するため、ファイルを書き換えたり削除する権限はシステム上持っていません。また、しおりデータは隔離されたアプリ専用領域にのみ保存されます。
